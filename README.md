# Seguimiento de Metas – Red CITE Pública

Herramienta institucional desarrollada en **Python + Streamlit** para consultar, monitorear y analizar el avance de metas y ejecuciones.

## 📋 Estructura del Proyecto
- `app.py`
- `requirements.txt`
- `README.md`
- `.gitignore`
- `data/`
- `assets/`
- `utils/`

## ⚙️ Ejecución Local
1. `pip install -r requirements.txt`
2. Colocar los archivos `meta_2026.xlsx` y `ejecucion_2026.xlsx` en la carpeta `data/`.
3. `streamlit run app.py`
